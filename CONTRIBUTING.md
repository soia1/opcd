# Contributing to OPCD Android

Thank you for your interest in contributing to OPCD Android!

## How to Contribute

1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/your-feature`).
3. Make your changes.
4. Commit with clear messages.
5. Open a Pull Request.

## Guidelines

- Keep changes minimal and focused.
- Follow the existing code style.
- Update documentation when needed.
- Respect the MIT License.
- Test your changes when possible.

## Communication

- Use English for code and technical documentation.
- Use Arabic for user-facing summaries if required.
